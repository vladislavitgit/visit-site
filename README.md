# Личный сайт

Самостоятельный сайт-визитка: главная, обо мне, контакты с картой и отзывы. Не обращается к Google Sheets и Telegram. Раздел отзывов оставлен пустым до появления настоящих отзывов.

Каталог товаров, услуги и форма заявки находятся в соседнем проекте `../Website-1`.

## Локальный запуск обоих сайтов

```sh
cd /Users/Macbook./Desktop/projects
php -S localhost:8000
```

- Визитка: http://localhost:8000/Website/
- Каталог: http://localhost:8000/Website-1/

Для отдельного размещения визитки достаточно `index.html`, `styles.css` и `script.js`. При разных доменах замените ссылку `../Website-1/` на адрес опубликованного каталога.
